# API reference

Base URL (local): `http://127.0.0.1:8000`. Interactive docs: `/docs` (Swagger UI) and `/redoc`. The machine-readable schema is `packages/api-client/openapi.json`, regenerated by `python scripts/export_openapi.py`.

All routes except `/health` live under `/api/v1`. If `API_KEY` is set on the server, send `X-API-Key: <key>`. Errors always look like:

```json
{"error": {"code": "not_found", "message": "No such job", "details": null}}
```

## All 26 operations

### Health and corpus

| Method | Path | Purpose |
|---|---|---|
| GET | `/health` | liveness: `{status, version, chunks, semantic_search}` |
| GET | `/api/v1/stats` | corpus statistics: chunks, documents, embedder, page range, whether semantic search is on |
| GET | `/api/v1/documents` | indexed sources with chunk counts |
| DELETE | `/api/v1/sources?key=` | remove a source and its chunks (`{deleted, chunks_removed, ok}`) |

### Ingestion (background jobs)

| Method | Path | Purpose |
|---|---|---|
| POST | `/api/v1/sources/files` | multipart upload of PDFs/audio; returns `202 {files, urls, job_id}` |
| POST | `/api/v1/sources/urls` | body `{urls: [...]}` of YouTube/GitHub/web links; returns `202` |
| GET | `/api/v1/jobs/{job_id}` | `{id, kind, status (queued/running/done/failed), progress[], result, error, created_at, finished_at}` |

### Asking and searching

## `POST /api/v1/ask`

Request:

```json
{
  "question": "How does a hash table handle collisions?",
  "k": 3,
  "mode": "technical",
  "model": null,
  "temperature": 0.2,
  "include_prompt": false,
  "no_cache": false
}
```

`mode` is the study style (technical, interview prep, quick summary). Response (abridged):

```json
{
  "answer": "A hash table has to deal with collisions ... [hashing.md]",
  "chunks": [
    {"doc": "hashing.md", "page": null, "end_page": null, "score": 0.62,
     "text": "Hash Tables > Collisions\nA collision occurs when ...", "url": null, "citation_url": null}
  ],
  "citations": [{"label": "hashing.md", "doc": "hashing.md", "page": null, "status": "ok"}],
  "unverified_citations": 0,
  "uncited": false,
  "model": "…",
  "cached": false,
  "prompt": null
}
```

## `POST /api/v1/ask/stream`

Same request body. The response is `text/event-stream`:

| Event | Data |
|---|---|
| `meta` | `{chunks, prompt?}` (sent first) |
| `token` | `{text}` (zero or more) |
| `done` | `{model, citations, unverified_citations, uncited, cached}` |
| `error` | `{code: llm_unavailable | llm_error | retrieval_error, message}` |

```bash
curl -N -X POST http://127.0.0.1:8000/api/v1/ask/stream \
  -H 'Content-Type: application/json' \
  -d '{"question":"What is the heap property?"}'
```

## Indexing a PDF

```bash
curl -F "files=@data/uploaded_files/notes.pdf" http://127.0.0.1:8000/api/v1/sources/files
# {"files":["notes.pdf"],"urls":[],"job_id":"4f1c…"}
curl http://127.0.0.1:8000/api/v1/jobs/4f1c…
# {"status":"done","result":{"indexed":1,"skipped":0,"failed":0,"chunks_added":212}, ...}
```

## Retrieval only

```bash
curl 'http://127.0.0.1:8000/api/v1/search?query=hash%20collisions&k=3'
```

Returns `{"chunks": [...]}` with the same `Chunk` objects as above; useful for debugging retrieval without a model key.

## Limits

Uploads: allowed types only, `%PDF-` signature checked, `MAX_UPLOAD_MB` (50) per file, bounded file count. Requests: `RATE_LIMIT_PER_MIN` (60) per IP, answered with `429` in the standard error shape.
